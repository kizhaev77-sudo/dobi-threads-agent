# Доби-агент для Threads — как запустить

## Что он делает

Агент — небольшая программа. Она работает в интернете сама, даже когда ваш компьютер выключен, и пользуется официальным API Threads, без браузера.

1. **Свои посты.** Раз в 6 часов публикует следующий пост из `posts.json`. Первая часть поста — польза, вторая (ответом в той же ветке) — «Кирилл, Петербург. Доби - ваш друг,собеседник и помощник.» и ссылка.
2. **Ответы на комментарии под вашими постами.**
   - Без Claude агент отвечает только на «спасибо/круто», «сколько стоит» и «где найти».
   - С Claude (шаг 5) отвечает на остальные вопросы.
   - Вопросы «как сделано / какой ИИ» и негатив не трогает, оставляет вам.
3. **Ветки саморекламы.** Находит свежие ветки, пропускает Казахстан, Беларусь, Украину, эзотерику и ветки «только для девочек / мастеров» и отвечает вашими текстами. Не больше 6 ответов за запуск и 30 в день. **Заработает только после одобрения Meta** (шаг 6), до этого агент просто пишет в журнал «поиск пока недоступен».

Работает с 07:00 до 24:00 по Москве, раз в час.

**Цена: 0 ₽.** GitHub и API Threads бесплатные. Claude — по желанию: при сотнях ответов в месяц меньше 1 $.

**Чего API не умеет:** ставить лайки. Отвечать в чужих ветках можно только после одобрения Meta.

## Шаг 1. Приложение в Meta (≈15 минут)

1. Зайдите на **developers.facebook.com** со своим аккаунтом Facebook/Instagram → «Мои приложения» → «Создать приложение».
2. Сценарий использования: **«Access the Threads API»** (доступ к Threads API). Название — например, «Dobi agent».
3. В приложении откройте **Use cases → Threads → Customize**. Включите разрешения:
   - `threads_basic`
   - `threads_content_publish`
   - `threads_manage_replies`
   - `threads_read_replies`
   - `threads_keyword_search`
4. Там же, раздел **Roles → Threads testers**: добавьте аккаунт **dobi_agent**.
5. В приложении Threads на телефоне примите приглашение: *Настройки → Аккаунт → Сайты и разрешения → Приглашения тестировщиков*.

## Шаг 2. Токен (ключ доступа)

1. В приложении Meta: **Use cases → Threads → Settings → User Token Generator** → «Generate» напротив dobi_agent. Войдите и разрешите доступ.
2. Скопируйте длинную строку — это **THREADS_TOKEN**. Никому её не показывайте, она даёт доступ к аккаунту.
3. Токен живёт 60 дней. Агент сам продлевает его каждый понедельник (шаг 4, GH_PAT).

## Шаг 3. GitHub — где агент будет жить (≈10 минут)

1. Зарегистрируйтесь на **github.com** (бесплатно).
2. «New repository» → имя `dobi-threads-agent` → **Private** → Create.
3. «Add file → Upload files» → перетащите все файлы из этой папки. Папку `.github` тоже: в ней расписание. Если она не загрузилась, создайте файлы `.github/workflows/agent.yml` и `refresh-token.yml` вручную через «Add file → Create new file» и вставьте содержимое.
4. **Settings → Secrets and variables → Actions → New repository secret:**
   - `THREADS_TOKEN` — токен из шага 2;
   - `GH_PAT` — нужен для автопродления токена (шаг 4);
   - `ANTHROPIC_API_KEY` — по желанию (шаг 5).

## Шаг 4. Автопродление токена

1. github.com → ваш аватар → **Settings → Developer settings → Fine-grained tokens → Generate new token**.
2. Доступ только к репозиторию `dobi-threads-agent`, права **Secrets: Read and write** и **Actions: Read and write** (второе — для будильника, шаг 4а). Срок — максимальный.
3. Скопируйте токен и сохраните его как секрет `GH_PAT`. Сохраните его и у себя — он нужен для будильника.

## Шаг 4а. Будильник cron-job.org (расписание GitHub ненадёжно)

1. Зарегистрируйтесь на **cron-job.org** (бесплатно) → **Create cronjob**.
2. URL: `https://api.github.com/repos/kizhaev77-sudo/dobi-threads-agent/actions/workflows/agent.yml/dispatches`
3. Расписание: **Custom** → минута `15`, часы `7–23`, часовой пояс **Europe/Moscow**.
4. Вкладка **Advanced**:
   - Request method: **POST**;
   - Headers: `Authorization: Bearer <токен GH_PAT>`, `Accept: application/vnd.github+json`;
   - Request body: `{"ref":"main","inputs":{"mode":"run"}}`.
5. **Test run** → ответ должен быть **204**, а во вкладке Actions появится запуск. Сохраните.

## Шаг 5 (по желанию). Умные ответы через Claude

На **console.anthropic.com** создайте API-ключ. Сохраните его как секрет `ANTHROPIC_API_KEY`. Без ключа агент отвечает шаблонами из `config.json` — тоже работает.

## Шаг 6. Одобрение поиска в Meta (для веток саморекламы)

В приложении Meta: **App Review → Permissions → threads_keyword_search → Request**. Обычно нужны:

- ссылка на политику конфиденциальности (например, iimagazin.ru/privacy);
- короткое видео, как приложение пользуется поиском;
- иногда подтверждение бизнеса.

Проверка занимает от нескольких дней. Meta может отказать — тогда агент всё равно ведёт ваши посты и комментарии под ними.

## Шаг 7. Ролик для ответов

API берёт видео только по публичной ссылке. Загрузите `dobi-osago.mp4` на сайт, например `https://iimagazin.ru/video/dobi-osago.mp4`. Ссылку впишите в `config.json` → `"promo_video_url"`. Пока ссылка пустая, агент отвечает текстами без слов «в ролике».

## Проверка

GitHub → вкладка **Actions** → «Dobi Threads agent» → **Run workflow**. Через минуту откройте запуск — в журнале видно, что агент сделал.

Чтобы сначала посмотреть без публикации, временно добавьте в `agent.yml` в блок `env:` строку `DRY_RUN: "1"`.

## Что можно менять без программиста

- **`posts.json`** — ваши посты. Каждый раз добавляйте новые с уникальным `id`.
- **`config.json`**:
  - тексты саморекламы (`promo_texts`);
  - стоп-слова (`skip_words`);
  - лимиты;
  - шаблоны ответов (`reply_templates`);
  - фразу `kir_phrase`.

Тексты вставляются дословно, как вы их написали.
